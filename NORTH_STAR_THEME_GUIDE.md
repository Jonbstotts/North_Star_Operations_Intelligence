# ORIVUE 5.0 — Optional North Star Theme

A provisional alternate application identity is available while the permanent visual
direction is being evaluated.

Select:

    Settings -> General -> Application theme -> North Star • Silver / Black

The alternate identity changes:

- application palette
- top-bar lockup
- splash identity
- login identity
- primary buttons and login controls
- major workspace surfaces
- window titles
- window/dock icon treatment on supported platforms

The North Star symbol is rendered locally with Java2D and uses a metallic three-point-star
treatment. The theme does not require external image files.

ORIVUE remains available in the same theme selector and can be restored at any time.

Holiday/seasonal themes remain separate from the identity decision and continue to work
through the existing theme system.
